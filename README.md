## LAYEAWARDS

The official website of the Lagos Young Entrepreneurs Awards: public site,
applicant registration, admin panel and public voting.

### Features

- Editorial public site with categories, gallery and blog
- Applicant registration and application submission
- Paystack-powered paid voting on the public ballot
- Live nominee profiles with running vote counts
- Admin panel to review applications, manage nominees and members
- Automated email notifications for applicants and nominees

### Tech stack

- Next.js, React, TypeScript
- Tailwind CSS
- GSAP and Lenis for motion
- Paystack for payments
